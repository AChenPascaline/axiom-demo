How Axiom Plugs Into vLLM
DROP-IN CONNECTOR
Axiom implements KVConnectorBase_V1 — vLLM's native KV connector interface. No model changes, no vLLM fork required.
KV CACHE INTERCEPT
Axiom intercepts KV block save and load events directly from the vLLM scheduler, storing blocks across HBM3 → DDR → NVMe tiers transparently.
GEOMETRY-AWARE
Block size and layer layout are derived from the live vLLM model config at runtime — no hardcoded values, compatible with any model architecture.
vllm --kv-connector AxiomV1Connector --kv-connector-module axiom_vllm  ·  no other flags required
